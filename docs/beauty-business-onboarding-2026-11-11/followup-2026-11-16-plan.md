# 뷰티 상품 노출·브랜드 선택·문의 버튼 보완 계획

## 확인된 사실

- 공개 디자이너 API가 승인된 모든 브랜드를 반환해 뷰티 브랜드도 디자이너 화면에 나온다.
- 같은 계정의 여러 뷰티 브랜드 작업공간은 선택 화면에서 브랜드명을 표시하지 않는다. 마스터 계정은 현재 선택이 없을 때 첫 작업공간을 자동 선택한다.
- 운영 공개 뷰티 목록에는 2026-11-16 기준 최근 상품들이 서로 다른 브랜드 이름으로 저장되어 있다. 캡처 속 두 번째 상품의 정확한 저장 상태·소유 브랜드는 인증된 자료가 없어 아직 확정할 수 없다.
- 오른쪽 카카오 문의 버튼은 `auth-nav.js`의 노란색 배경을 사용한다.

## 작업

1. 공개 디자이너 목록·상세·스타일링 보드가 패션 작업공간의 브랜드만 보여주게 한다. 검증은 API와 화면의 뷰티 브랜드 제외, 기존 패션 상품 유지다.
2. 작업공간 선택 화면에 브랜드명을 표시하고 여러 뷰티 작업공간을 임의로 첫 번째 선택하지 않게 한다. 상품 관리에 현재 브랜드와 전환 경로를 보여준다. 검증은 다중 브랜드 선택 테스트와 화면 확인이다.
3. 문의 버튼을 눈에 띄는 파란색으로 바꾼다. 검증은 PC·모바일 화면과 명도 대비다.
4. 빌드·관련 회귀 테스트를 실행하고 운영 반영 후 공개 상품 수와 기존 화면을 확인한다. 상품 2건의 실제 DB 상태는 인증된 조회가 가능할 때만 확정한다.
