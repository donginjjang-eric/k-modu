# 작업 맥락

- 앞선 카카오 문의 버튼 색상 변경과 다른 요청이다. 새 캡처의 노란 표시는 `/beauty/join`에서 로그인 뒤 생성되는 `기존 뷰티 브랜드 센터 열기` 버튼이다.
- 첫 화면 오른쪽 바로가기는 `auth-nav.js`가 만든다. 기존 디자이너 스튜디오 링크는 `/dashboard/designer`다.
- 뷰티 스튜디오 링크는 기존 `/dashboard/beauty`를 재사용한다. 로그인하지 않았다면 서버가 로그인 화면으로 안내한다.
- 기존 미추적 파일과 이전 작업은 보존한다.
- 가입 화면 기존 센터 버튼과 첫 화면 뷰티 바로가기에 장밋빛 `#a12d5a`를 사용했다. 첫 화면 바로가기는 홈에서만 디자이너 스튜디오 위에 표시한다.
- 관련 테스트 17개와 타입 검사·인라인 스크립트 검사·webpack 운영 빌드가 통과했다. `tests/beauty-products.test.mjs`의 CSS 버전 문자열 기대값은 이번 변경 이전 HEAD의 `beauty.html`과도 맞지 않아 기존 실패로 확인했다.
- 로컬 PC 1440px과 모바일 390px에서 첫 화면 네 버튼의 표시를 확인했다. 가입 화면 버튼은 인증 GET만 가짜 응답으로 재현해 색과 폭을 확인했다. 실제 로그인이나 상품 선택 요청은 수행하지 않았다.
- 앞선 턴의 카카오 문의 버튼 파란색 변경은 캡처 표시를 잘못 해석한 결과였다. 본 요청에서 이를 원래 노란색으로 복구하고 가입 화면의 지정 버튼과 새 뷰티 스튜디오만 장밋빛으로 강조한다.
- `b7ad2d8` 배포가 Railway 성공 상태다. 운영 첫 화면 PC 1440px·모바일 390px에서 뷰티 스튜디오가 디자이너 스튜디오 위에 표시되고 색은 rgb(161, 45, 90)이다. 카카오 문의는 원래 노란색 rgb(254, 229, 0)이다. 모바일 가로 넘침은 없다.
- 운영 가입 화면에서도 인증 GET만 가짜 응답으로 재현하면 기존 브랜드 센터 버튼이 rgb(161, 45, 90)으로 나온다. 실제 운영 계정 로그인·브랜드 선택 요청은 실행하지 않았다.
- 운영 `/dashboard/beauty`에 비로그인 접근 시 307로 `/login?notice=designer_login&next=%2Fdashboard%2Fbeauty`에 이동한다.
