# 뷰티 사업자 가입·관리 PRD 작성 계획

1. 현재 신청·로그인·뷰티 센터·관리자 기능을 확인한다. 확인 기준은 화면과 서버 로직을 구분해 기록하는 것이다.
2. 기존 기능을 재사용하는 뷰티 전용 간편 가입·즉시 상품 공개·사후 관리 흐름을 설계한다. 확인 기준은 권한·상태·예외 흐름이 끊기지 않는 것이다.
3. 단계별 범위와 수용 기준을 PRD에 정리한다. 확인 기준은 구현 담당자가 추가 해석 없이 첫 단계 작업을 쪼갤 수 있는 것이다.

초기 PRD 작성 단계에서는 서비스 코드와 운영 데이터를 변경하지 않았다.

## 2026-11-11 화면 시안 작업

1. PRD를 바탕으로 뷰티 전용 간편 가입 화면을 독립 미리보기 파일로 만든다. 확인 기준은 실제 가입 API를 호출하지 않는 것이다.
2. PC와 모바일 크기에서 배치·글자·이미지를 확인한다. 확인 기준은 화면 캡처와 주요 요소의 가시성이다.

이 단계에서도 운영 사이트와 실제 가입 기능은 변경하지 않는다.
