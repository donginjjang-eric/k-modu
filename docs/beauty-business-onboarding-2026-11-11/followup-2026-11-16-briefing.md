# 뷰티 상품 노출과 관리 화면 수정 결과

## 무엇이 달라졌나

- 뷰티 전용 브랜드와 화장품은 이제 공개 디자이너 화면에 나오지 않는다. 뷰티 상품은 뷰티 화면에서 계속 볼 수 있다.
- 한 계정에 브랜드가 여러 개면 선택 화면에서 브랜드 이름을 보여준다. 상품 관리 화면에는 현재 브랜드와 다른 브랜드로 바꾸는 링크를 넣었다.
- 상품 등록·수정·삭제도 선택한 브랜드 센터의 상품 분야를 확인한다. 다른 분야 상품은 해당 센터에서 수정할 수 없다.
- 이후 전달된 확대 캡처에서 색상 변경 대상이 가입 화면의 `기존 뷰티 브랜드 센터 열기` 버튼임을 확인했다. 카카오 문의 버튼은 원래 노란색으로 복구했다.

## 실제 확인 결과

- 운영 디자이너 브랜드는 20개에서 14개로 정리됐다. 디자이너 화면의 상품 지표는 124개에서 90개가 됐다. 뷰티 상품 34개는 그대로다.
- 뷰티 전용 브랜드의 기존 디자이너 상세·스타일링 보드 주소는 404로 응답한다. 디자이너·뷰티·뷰티 가입 화면은 모두 정상 응답한다.
- 색상 변경 대상을 바로잡아 가입 화면 버튼과 첫 화면 뷰티 스튜디오 바로가기를 장밋빛으로 표시한다. 모바일 390px에서 가로 넘침은 없었다.
- 관련 테스트 33개, 타입 검사, 운영 빌드가 통과했다. 기본 Turbopack 빌드는 로컬 `.next` 연결 파일 충돌로 중단됐고 webpack 빌드는 성공했다.

## ‘두 상품 중 하나만 보임’ 확인 방법

1. 뷰티 브랜드 센터의 상품 관리에서 **현재 브랜드** 이름을 확인한다.
2. **다른 브랜드 선택**을 눌러 등록에 사용한 브랜드를 각각 확인한다.
3. 그래도 상품이 없으면 상품명 두 개와 등록에 사용한 계정을 알려준다. 현재 공개 자료만으로는 비공개 상품의 저장 상태를 확인할 수 없다.

운영 사이트에 수정 사항을 반영했다. 상품을 임의로 옮기거나 다시 등록하지 않았다.
