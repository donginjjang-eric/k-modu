# 뷰티 브랜드 가입·상품 등록 브리핑

작성일. 2026년 11월 11일.

운영 반영 상태. 새 가입 화면이 열리고 기존 뷰티·디자이너·크리에이터 페이지가 정상 응답합니다.

## 이번에 연결한 흐름

1. 뷰티 페이지에서 **뷰티 브랜드 가입**을 누릅니다.
2. 구글 계정으로 로그인하고 브랜드명, 담당자, 상품 분야, 이메일을 입력합니다. 홈페이지·인스타그램 주소는 선택 사항입니다.
3. 가입하면 뷰티 브랜드 센터의 **상품 관리**로 이동합니다. 사업자등록증 제출과 관리자 사전 승인은 필요하지 않습니다.
4. 상품 사진과 이름을 올리면 공개 설정에 따라 뷰티 페이지에 표시됩니다.

가입 화면. [뷰티 브랜드 가입](https://www.k-modu.co.kr/beauty/join).

## 관리자가 처리할 수 있는 일

| 상황 | 관리자 화면에서 하는 일 | 결과 |
| --- | --- | --- |
| 문제가 있는 상품 | 상품 관리에서 **관리자 비공개**를 누르고 이유를 입력합니다. | 공개 목록에서 사라지고 브랜드가 직접 다시 공개하거나 수정할 수 없습니다. |
| 해결된 상품 | 같은 상품의 **복구하기**를 누릅니다. | 상품의 관리자 차단이 풀립니다. |
| 문제가 있는 브랜드 | 브랜드 관리에서 **이용 중단**을 누르고 이유를 입력합니다. | 해당 브랜드의 센터 접근과 상품 등록이 막히고 공개 상품도 내려갑니다. |
| 해결된 브랜드 | 브랜드 관리에서 **승인**을 누릅니다. | 브랜드 작업공간을 다시 이용할 수 있습니다. |

기존 패션 가입과 크리에이터 센터는 별도로 유지했습니다. 계정과 로그인 방식은 기존 서비스를 함께 사용합니다.

## 검수 기록

- PC와 모바일에서 가입 화면을 실제 브라우저로 확인했습니다. 모바일 가로 넘침과 이미지 깨짐은 없었습니다.
- 뷰티 페이지의 가입 버튼이 새 화면으로 이어지는 것을 확인했습니다.
- 로그인하지 않은 계정으로 가입 API를 호출하면 차단되는 것을 확인했습니다.
- 가입·상품·관리자·기존 작업공간 관련 테스트 66개와 운영 빌드가 통과했습니다.
- 배포 전 운영 사이트에서 뷰티·디자이너·크리에이터 페이지가 열렸고 뷰티 상품 29개가 조회됐습니다.
- 배포 후에도 위 세 페이지와 새 가입 화면이 정상 응답했고, 뷰티 상품은 동일하게 29개입니다. 구글 로그인 버튼은 구글 인증 화면으로 연결됩니다.

## 추가 실사용 확인

로컬 개발 환경에는 운영 DB와 구글 로그인 설정이 없습니다. 따라서 실제 구글 계정으로 새 브랜드를 만들고 사진을 올려 공개 페이지에 나타나는 과정, 관리자 계정으로 제재·복구하는 과정은 실제 계정에서 확인해야 합니다. 운영 DB에 시험 브랜드를 만드는 요청은 자동 승인 검토에서 실데이터 생성 위험을 이유로 거절됐고, 시험 브랜드는 생성하지 않았습니다. 코드와 테스트 통과만으로 이 과정을 실사용 검수 완료라고 표시하지 않습니다.
