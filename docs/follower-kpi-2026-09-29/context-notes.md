# 크리에이터 팔로워 합계 컨텍스트

2026-09-29 조사 결과, `creators.html`은 모든 카드의 `data-followers`를 숫자로 변환해 더한다. 최근 추가된 말레이시아 미팅 14명과 베트남 아티스트 7명의 값은 빈 문자열이다. 따라서 118명 중 97명의 수치만 더한 56,620,886이 표시된다.

팔로워 수가 없는 21명에게 임의 수치를 넣지 않는다. 수치가 알려진 카드의 합계임을 제목과 설명에 표시한다. 이 값은 플랫폼 간 중복 팔로워를 제거한 고유 도달 인원이 아니다.

수정 후 제목은 `Recorded Followers`, 설명은 실행 시 카드 수로 계산한 `팔로워 수 입력 97/118명 · 미입력 21명 제외`이다. 합계 56,620,886 자체는 변하지 않는다. `npm run check:inline-scripts`와 `npm run build`가 통과했다. 빌드의 `src/lib/storage.ts` 추적 범위 경고는 이번 수정 파일과 무관하다.

추가 요청에 따라 공개 프로필을 직접 확인했다. Instagram HTML의 `og:description`은 K·M 단위의 반올림 표시이고, TikTok 브라우저 HTML에서는 계정 `uniqueId`와 `followerCount`가 일치하는 것을 확인했다. 14명 Instagram 900,000명, TikTok 833,079명, 7명 Instagram 19,393,000명이다. 신규 21명 합계는 약 21,126,079명이며 기존 56,620,886명을 더한 원시 합계는 77,746,965명이다. Instagram 수치가 반올림돼 있으므로 운영 KPI는 대략 값으로 보여야 한다.

세 관련 테스트 4개와 인라인 스크립트 검사, `npm run build`가 통과했다. Chrome 로컬 렌더링에서 원시 합계 77,746,965, 화면 표시 `약 7,800만`, 집계 118/118명, 카드 118개를 확인했다.
