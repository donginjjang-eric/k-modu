# 크리에이터 팔로워 합계 컨텍스트

2026-09-29 조사 결과, `creators.html`은 모든 카드의 `data-followers`를 숫자로 변환해 더한다. 최근 추가된 말레이시아 미팅 14명과 베트남 아티스트 7명의 값은 빈 문자열이다. 따라서 118명 중 97명의 수치만 더한 56,620,886이 표시된다.

팔로워 수가 없는 21명에게 임의 수치를 넣지 않는다. 수치가 알려진 카드의 합계임을 제목과 설명에 표시한다. 이 값은 플랫폼 간 중복 팔로워를 제거한 고유 도달 인원이 아니다.

수정 후 제목은 `Recorded Followers`, 설명은 실행 시 카드 수로 계산한 `팔로워 수 입력 97/118명 · 미입력 21명 제외`이다. 합계 56,620,886 자체는 변하지 않는다. `npm run check:inline-scripts`와 `npm run build`가 통과했다. 빌드의 `src/lib/storage.ts` 추적 범위 경고는 이번 수정 파일과 무관하다.
