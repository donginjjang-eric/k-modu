# 크리에이터 팔로워 합계 표시 수정 계획

현재 화면의 합계가 어떤 카드의 팔로워를 더하는지 확인하고, 부분 집계라는 사실을 화면에 표시한다. 확인되지 않은 팔로워 수는 추정하지 않는다.

1. 카드별 집계 수와 합계를 재현한다. 검증 기준은 화면의 56,620,886과 일치하는지 확인한다.
2. KPI 제목과 설명을 실제 집계 범위에 맞게 수정한다. 검증 기준은 전체 카드 수와 집계된 카드 수가 화면에 표시되는지 확인한다.
3. 프로젝트 검사와 빌드를 실행한다. 검증 기준은 관련 명령이 통과하는지 확인한다.

## 추가 요청. 빠진 21명까지 대략 합산

4. 14명의 인스타그램·틱톡과 7명의 인스타그램 공개 프로필 수치를 확인한다. 검증 기준은 계정 식별자와 수치가 모두 확인되는지 확인한다.
5. 확인한 값을 카드 데이터에 기록하고 KPI를 반올림된 추정 합계로 표시한다. 검증 기준은 118명 모두 집계되고 플랫폼 간 팔로워 중복 가능성을 설명하는지 확인한다.
6. 검사·빌드·로컬 브라우저 확인을 실행한 뒤 운영 반영을 확인한다.
