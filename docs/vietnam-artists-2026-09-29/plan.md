# 베트남 아티스트 7명 추가 계획

사용자가 제공한 `Vietnam_Artists_KR.pptx`의 7명을 K-MODU 크리에이터 목록에 추가한다.

1. 공식 SNS 계정과 게시물 사진을 확인한다. 이름과 사진 출처가 맞는지 기록한다.
2. 실제 사진을 사용해 서로 다른 카드 7장과 썸네일을 만든다. 확인되지 않은 팔로워 수는 공개하지 않는다.
3. 기존 카드·관리자 명단에 7명을 고유 키로 추가한다. 전체 공개 카드 목표는 118명이다.
4. 이름·계정·사진·카드 수를 검증하고 테스트와 빌드를 실행한다.
5. 커밋·푸시·운영 배포와 운영 DB를 확인한다.

기존 미추적 파일과 다른 작업물은 건드리지 않는다.
