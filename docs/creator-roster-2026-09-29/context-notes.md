# 신규 미팅 크리에이터 14명 작업 노트

- 2026-09-29. 이전 24명은 `data/malaysia-meeting-creators.js`에서 공개하며, DB `creator_accounts`에도 관리자 온보딩으로 동기화한다.
- 이번 14명과 기존 공개 데이터의 Instagram/TikTok 핸들 중 일치하는 항목은 없다. Fatin과 Arisha는 표시 이름만 중복되므로 새 키를 별도로 사용해야 한다.
- 사용자 제공 단가 3종은 계약 협의 정보이므로 공개 데이터나 공개 이미지에 넣지 않는다.
- 신규 명단에는 팔로워 수 및 실제 사진 원본이 없다. 수치를 추정하거나 타인의 사진을 매칭하지 않는다.
- 기존 카드 수는 97명이다. 사용자 제공 명단을 모두 추가하면 111명이다.
- 기존 미추적 파일은 이 작업의 산출물이 아니므로 유지한다.
- 사용자는 인스타그램이나 틱톡에서 실제 사진을 내려받아 합성·생성하는 방식을 지정했다. Instagram 공개 페이지의 `og:image`에서 14명 모두 100×100 프로필 사진을 확보했다.
- 사진은 원본 계정의 작은 초상으로 그대로 쓰고, 생성 이미지는 인물 없는 공통 에디토리얼 배경으로만 사용한다. 실제 인물의 얼굴을 AI로 새로 만들지 않는다.
- Instagram 공개 메타에는 팔로워 수가 K 단위로 반올림돼 있으므로, 정확한 수치인 것처럼 등록하지 않는다. TikTok 팔로워 수 역시 확인할 수 없어 새 14명의 공개·관리자 팔로워는 미확인으로 둔다.
- `Nurin`의 Instagram 표시명은 `Mimi`, `Fatin` 및 `Arisha`의 Instagram 표시명은 공란이지만 사용자 제공 핸들과 프로필 사진 주소는 일치한다. 공개 이름은 사용자가 준 이름을 유지한다.
- 카드 이미지 배경은 `image_gen` 도구로 1장 생성했다. 프롬프트는 아이보리·샴페인 원단과 종이 질감의 인물·텍스트 없는 세로형 K-MODU 에디토리얼 배경이다.
- 사용자 지시 변경. 14명 일괄 등록 전에 한 명부터 보여달라고 했다. 따라서 앞서 만든 14명 공개 카드·관리자 동기화 코드와 14개 아바타 에셋은 사이트에서 모두 제거했다. 기존 공개 목록 97명은 유지된다.
- Aweenzul 실제 게시물 `https://www.instagram.com/aweenzul/p/DWlswUTEgm4/`의 사진을 선택했다. 공개 페이지 DOM의 설명은 `Photo by Aween Zul on April 01, 2026.`이고, 내려받은 원본은 480×640픽셀이다.
- `image_gen`으로 사진 포함 포스터도 시도했으나 얼굴을 새로 그릴 여지가 있어 사용하지 않았다. 최종 시안은 생성된 인물 없는 배경 위에 원본 사진을 일반 리사이즈로 배치해 만들었다. 원본 사진과 최종 이미지, 배경을 이 폴더에 함께 보관한다.
- 현재 시안은 사용자 검토용이며 사이트와 DB에는 반영하지 않았다. 새 명단의 이름이나 단가는 공개되지 않는다.
- 사용자가 Aweenzul 시안의 방향을 확인한 뒤, 기존 사이트 카드처럼 다양한 디자인으로 나머지 13명도 진행하도록 요청했다. 이제 14명 등록과 운영 반영을 추진한다.
- 14명 모두 제공된 Instagram 계정의 게시물 페이지에서 직접 사진을 확인해 원본과 게시물 URL을 `source-manifest.json`에 기록했다. 새 카드에는 이 원본만 사용한다. 인물 없는 생성 배경은 아이보리·차콜·블러시·코발트·올리브 5종이다.
- 실제 게시물 사진으로 14장 900×1200 카드와 각 360/720픽셀 썸네일을 제작했다. Aweenzul은 사용자 확인 시안을 그대로 사용했다. 전체 카드 검토 이미지는 `card-review.jpg`다.
- 새 14명의 팔로워 수는 미확인이므로 공개 카드에는 `—`, 관리자 데이터에는 0과 확인일 없음으로 저장한다. 기존 24명의 팔로워 확인일은 유지한다. 사용자 제공 단가는 공개 데이터에서 제외했다.
- 명단·동기화 테스트 6개, 데이터 경로 테스트 2개, `npm run build`, 로컬 Chrome 렌더링 및 새 이미지 28개 HTTP 응답 검사가 통과했다. Chrome DOM에서 실제 카드 111개와 새 카드 14개를 확인했다.
