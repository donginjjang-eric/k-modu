# 신규 미팅 크리에이터 14명 등록 계획

사용자가 Aweenzul 실제 사진 카드 시안을 확인하고 나머지 인플루언서도 다양한 스타일로 진행하도록 요청했다.

1. 나머지 13명의 Instagram 공개 게시물에서 계정과 사진 출처를 확인한다.
2. 각자의 실제 사진을 사용하고 다양한 레이아웃·배경·글꼴로 카드 14장을 완성한다. 인물 얼굴은 생성하지 않는다.
3. 카드 이미지와 360/720픽셀 썸네일을 저장하고, 14명을 기존 97명과 구분해 공개 목록과 관리자 명단에 추가한다.
4. 동명이인 계정, 카드 수 111명, 단가 비공개, 미검증 팔로워 수 제외를 테스트한다.
5. 빌드와 화면을 확인한 뒤 의미 단위 커밋, 푸시, 운영 사이트 검증까지 진행한다.

기존 사용자 미추적 파일은 보존한다.
