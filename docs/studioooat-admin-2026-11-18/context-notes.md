# 작업 맥락

- 사용자가 studioooat@gmail.com 한 계정에 일반 관리자 권한을 부여하도록 승인했다.
- 기존 크리에이터 프로필을 관리자 데모 프로필로 갱신하는 코드가 있어 먼저 보존하도록 수정한다.
- Railway CLI에는 인증 세션이 없다. 기존 배포 권한으로 일반 역할과 관리자 센터 권한을 한 번 적용하는 방법을 검토한다.
- 크리에이터 프로필 보존과 미리보기 분리를 별도 커밋으로 배포한다. 실제 Postgres 테스트에서 원본 프로필 전체와 기존 미리보기 생성·재사용을 확인했다. 운영 빌드와 관련 테스트 25개가 통과했다.
- 승인 작업은 정식 Railway 환경과 서비스에서만 실행한다. 정확히 한 계정이 기존 승인 크리에이터·뷰티 브랜드를 소유하는지 확인한 후 관리자 역할과 활성 작업공간을 추가하고 변경 기록을 남긴다. 확인 실패는 트랜잭션을 되돌리고 새 배포를 시작하지 않는다.
- 격리된 Postgres에서 다른 계정과 작업공간 보존, 소유권 불일치 시 롤백, 재실행 후 권한 중복 및 재부여 방지를 검증했다. 스키마·운영 시작 관련 테스트 22개가 통과했다.
